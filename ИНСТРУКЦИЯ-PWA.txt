САДИК НА СВОБОДНОМ — PWA (устанавливаемое автономное приложение)

ВАЖНО: PWA нельзя установить из локального HTML-файла напрямую. Сначала загрузите эти файлы на HTTPS-хостинг, например GitHub Pages. После первого открытия и завершения кэширования приложение работает без интернета.

БЫСТРЫЙ СПОСОБ ЧЕРЕЗ GITHUB PAGES
1. На компьютере войдите в GitHub или создайте аккаунт.
2. Создайте новый репозиторий (например, sadik-catalog). Для простоты можно выбрать Public.
3. Загрузите в корень репозитория ВСЕ файлы и папку images из этого архива. Не загружайте сам ZIP вместо файлов.
4. В репозитории откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку /(root), затем Save.
6. Подождите публикации и откройте адрес Pages, который покажет GitHub (обычно https://ИМЯ.github.io/sadik-catalog/).
7. Откройте этот адрес в Chrome на Android. Оставьте страницу открытой при стабильном интернете, пока загрузятся и закэшируются фотографии (около 30 МБ). Не закрывайте вкладку слишком рано.
8. В Chrome нажмите ⋮ → «Установить приложение» или «Добавить на главный экран».
9. Проверьте работу: включите авиарежим и запустите «Каталог цветов» с главного экрана.

ОБНОВЛЕНИЯ
После изменения файлов на GitHub обновите страницу приложения при наличии интернета. Service worker может обновить кэш новой версией.

ПРИМЕЧАНИЯ
- Публикация делает каталог доступным по ссылке в интернете. Учитывайте это, если в каталоге появятся приватные данные.
- При первом открытии браузер должен скачать фотографии для офлайн-режима.
- Сайт использует локальные изображения; поиск и фильтрация работают в браузере.
